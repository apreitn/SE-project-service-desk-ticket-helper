# Service Desk Ticket Helper

## Product idea
Service Desk Ticket Helper is a simple web-based tool that helps users create clear, structured IT support tickets.

## Problem
Many IT support requests are incomplete, unclear, or missing important technical details. This slows down troubleshooting, creates unnecessary back-and-forth communication, and makes escalation harder.

## Target users
The main users are:
- IT service desk agents
- Students learning IT support
- Employees who need to report IT issues
- Junior technical support specialists

## Core features
- Create structured incident descriptions
- Collect required troubleshooting details
- Generate clear escalation text
- Store common issue templates
- Track ticket status and notes
- Keep a history of submitted cases

## Example use case
A user reports that Outlook is not working. Instead of writing only "Outlook problem", the tool helps collect:
- user name
- device name
- application version
- error message
- steps already tried
- business impact
- urgency
