# Architecture Overview

The MVP architecture is intentionally simple.

## Frontend
- HTML for structure
- CSS for styling
- JavaScript for logic and interactions

## Application Flow
1. User opens application
2. User fills ticket form
3. Application validates required fields
4. Structured ticket is generated
5. User copies or exports the ticket

## Design Principles
- Simplicity first
- Easy maintenance
- Clear file organization
- Minimal dependencies
