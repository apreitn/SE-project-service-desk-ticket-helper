# Project Management Approach

This project will use a hybrid Agile approach based mainly on Kanban principles with lightweight Scrum elements. The focus is on continuous progress, small iterative improvements, and maintaining a clear backlog of tasks.

Development work will be divided between the human developer and AI assistants. The human developer will be responsible for:
- defining architecture
- reviewing generated code
- validating functionality
- making final technical decisions
- maintaining project direction

AI assistants will support:
- boilerplate code generation
- UI structure suggestions
- documentation drafting
- simple refactoring
- test generation
- repetitive implementation tasks

The project will prioritize maintainability, simplicity, and clear documentation over feature complexity.
