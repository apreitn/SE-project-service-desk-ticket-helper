# Deployment

## Hosting platform
The application is deployed using GitHub Pages.

## Reason for choosing GitHub Pages
GitHub Pages was selected because the MVP is a static frontend application built with HTML, CSS, and Vanilla JavaScript. It does not require a backend server, database, or build pipeline.

## Deployment source
The application is deployed from:

- Branch: `master`
- Folder: `/root`
