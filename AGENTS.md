# AGENTS.md

## Project Overview
Service Desk Ticket Helper is a web-based application for creating structured IT support tickets.

The main goal is to help users provide complete and clear incident information for faster troubleshooting and escalation.

## Main Features
- Structured ticket creation
- Incident templates
- Troubleshooting checklist support
- Escalation text generation
- Ticket history and notes
- Status tracking

## Technology Stack
- HTML
- CSS
- JavaScript
